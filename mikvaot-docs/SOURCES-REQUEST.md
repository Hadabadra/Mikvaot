# פנייה למקורות הנתונים (נוסח לשליחה)

שלום רב,
אני מפתחת את התוסף "מקוואות" לתוכנת אוצריא — מדריך מקוואות חינמי שעובד בלי אינטרנט (כתובת, טלפון ושעות בלבד; ללא פרסומות וללא איסוף מידע).
הפרטים שלכם מופיעים בתוסף עם ציון המקור. נשמח לאישורכם לעדכן אותם מדי תקופה מתוך האתר שלכם, ולקבל רשימה מעודכנת אם יש (גם מקוואות גברים וכלים).
אפשר לראות את התוסף כאן: https://github.com/Hadabadra/Mikvaot
בתודה,
המפתחת

נמענים מוצעים: המועצות הדתיות (ירושלים, טבריה ועוד), עיריית בני ברק — מחלקת המקוואות, עיריית אלעד — המחלקה לשירותי דת, עיריית ביתר עילית — שירותי דת.
