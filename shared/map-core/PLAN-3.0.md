# מפה משותפת 3.0 — המפה המאוחדת (04.11.2026)

מקור: `shared/REQUESTS-2026-11-04.md`, סעיף "פתוח — המפה המשותפת המאוחדת". מעקב: Prayer-pointA#23, madaei-hatanach#258.
מקור יחיד: `shared/map-core/` במאגר הזה. כל תוסף מעתיק את הקבצים בזמן האריזה.

## מה נכנס לבסיס המשותף (map-core 3.0 / map-ui 3.0)
1. **סגנון מפה** (תפריט "סגנון" בחלון השכבות, נשמר):
   - **צבעוני — כמו עינים למקרא** (ברירת מחדל): יבשה חומה-בהירה, ים כחול-אפור, גבולות חומים, נהרות כחולים, עם כל 378 התוויות של עינים למקרא (ארצות, ערים, ימים — כולל המזרח התיכון).
   - **ארצות בצבעים**: כל ארץ בצבע (מצב 2.1).
   - **חום-לבן**: כמו כיוון תפילה.
2. **מצבי תצוגה** (שורת מצבים במפה, כמו בכיוון תפילה): מפה · רחובות · סביבה קרובה · כדור.
   - כדור = הטלה אורתוגרפית אמיתית (map-core `proj:'globe'`), גרירה מסובבת את הכדור, הצד הנסתר לא מצויר.
3. **ירושלים** (רק כשהתוסף מבקש, כיוון תפילה): קו + ראש חץ לירושלים בכל המצבים, כולל בכדור (קו גדול-מעגל).
4. **כל הכפתורים הקיימים נשארים** (מיקום, מרכוז, מסך מלא, שכבות, +, שרטוט, מסלול הליכה, מידע, הדרכה, סיבוב, צפון).

## איך כל תוסף מקבל את המפה
| תוסף | שילוב ב-3.0 | מה לא הורד |
|---|---|---|
| מקוואות | סנכרון `tools/sync-shared.sh` | הכול |
| גבולות עירוב | ה-CI מוריד לפני האריזה | הכול |
| כיוון תפילה | כפתור "מפה מאוחדת" שפותח את MapUI במסך מלא עם `jerusalem:true` ומיקום המשתמש | כל המפות והכפתורים של כיוון תפילה נשארים כמו שהם |
| עינים למקרא | כפתור "מפה מאוחדת" במפת המקומות שפותח את MapUI עם המקומות לפי סינון התקופות | מפת Leaflet (לוויין, מסע, קישורי Google) נשארת |

**למה לא החלפה מלאה עכשיו:** ב-03.11 נקבע לגבי עינים למקרא "לשלב במלואו או לא בכלל", וב-REQUESTS נכתב "רק אחרי בדיקה — להחליף בכל תוסף". לכן ב-3.0 המפה המאוחדת נכנסת **לצד** המנועים הקיימים בכיוון תפילה ובעינים למקרא. אחרי בדיקה באוצריא — שלב 4 מחליף את המנועים הישנים (מעקב ב-Prayer-pointA#23 ו-madaei-hatanach#258).
