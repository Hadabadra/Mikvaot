# shared — מקור יחיד לכל התוספים של חד בדרא

כל מה שמשותף ליותר מתוסף אחד נמצא **רק כאן** (Hadabadra/Mikvaot, ענף main, תיקייה `shared/`). מתקנים כאן, וכל תוסף מעתיק כמו שהוא לפני אריזה.

| תיקייה | מה | מי משתמש |
|---|---|---|
| `map-core/` | המפה המשותפת (חישובים + מסך מפה + שכבות בין תוספים) | מקוואות, גבולות עירוב, כיוון תפילה (שכבות), עינים למקרא |
| `basemap/` | מפת העולם בעברית (Natural Earth) | מקוואות, גבולות עירוב |
| `streets/` | רשימת הערים שהרחובות שלהן מובנים | מקוואות, גבולות עירוב |
| `report/` | דיווח תקלות אוטומטי דרך מערכת הדיווחים של אוצריא (0.9.98.3) + סיכום ה-SDK | כל התוספים |
| `promo/` | המלצה על "אחת שאלתי" (1.1.0: דף HTML עם קישורים לחיצים במצב מנותק) | כל התוספים |

סנכרון: מקוואות `tools/sync-shared.sh` · גבולות עירוב — CI · כיוון תפילה `kivun-tefila-build/sync-shared.sh` · לשון הקודש ועינים למקרא — מעתיקים `report/` ו-`promo/` בגרסה הבאה שלהם.
