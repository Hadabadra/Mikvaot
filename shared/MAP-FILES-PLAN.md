# תמיכה בקובצי מפות לא מקוונים — תכנון (16.11.2026)

בקשה (סבב סיום 7/7): בכל התוספים שיש בהם מפה (כיוון תפילה, מקוואות, גבולות עירוב, טהרת כהנים, עינים למקרא) —
לבחור קובץ מפות מהמחשב ולראות מפה חיה ואיכותית, עם חיפוש מקומות ורחובות, מסך מלא, ומחובר לכל הממשק של התוסף.
דוגמאות שנזכרו: קובצי המפות של Windows, ו-MapsOffline (קובץ `MapsOffline-2026-11-02.mapsdata`, פורסם במתמחים טופ).

**סטטוס: לא בוצע בסבב הזה — תוכנן בלבד.** הסיבות למטה. הפיתוח מושהה עד ~מאי 2027.

## מה אפשר ומה לא

| פורמט | אפשר? | איך | הערות |
|---|---|---|---|
| GeoJSON / KML / KMZ / GPX | כן, קל | קריאת הקובץ (fs) → שכבת קווים/נקודות במפה המשותפת | אין רקע מפה, רק שכבה |
| MBTiles (רסטר) | כן | sql.js (WASM, כ-650KB) קורא אריחים מהקובץ → שכבת רקע | גבולות עירוב קרוב למגבלת 50MB (47.9MB) — לטעון את sql.js רק בלחיצה |
| MBTiles / PMTiles (וקטור) | אפשרי, כבד | צריך מנוע ציור וקטורי (MapLibre, כמיליון בתים) | חיפוש רחובות — רק אם בקובץ יש שכבת שמות |
| PMTiles (רסטר) | כן | ספריית pmtiles (קטנה) + קריאת טווחים מהקובץ | |
| מפות Windows (`%ProgramData%\Maps`) | **לא** | פורמט סגור ומוצפן של מיקרוסופט, אין תיעוד ציבורי | אפשר רק לפתוח את אפליקציית המפות של Windows דרך הגשר |
| MapsOffline `.mapsdata` | **לא ידוע** | צריך דוגמה קטנה של הקובץ ותיאור הפורמט מהמפתח שלה | אם זה SQLite/ZIP עם אריחים — ייכנס כמו MBTiles |
| חיפוש מקומות ורחובות מתוך הקובץ | חלקי | בכיוון תפילה יש כבר מאגר רחובות; לקובץ חיצוני — רק אם הוא כולל שמות | גיאוקודר מלא דורש מאגר נפרד (או את הגשר) |

## הצעת מימוש (כשהפיתוח יחודש)
1. במפה המשותפת (`shared/map-core`, `shared/map-ui`): כפתור "קובץ מפות…" בתפריט השכבות → `fs.pickFile`
   (או תיבת גרירה) → זיהוי לפי סיומת וכותרת הקובץ (SQLite `SQLite format 3`, ZIP `PK`, PMTiles `PMTiles`).
2. מתאם `FileTiles` לכל פורמט: `getTile(z,x,y) → ImageBitmap`. שכבת רקע חדשה במפה המשותפת, נשמרת בבחירה
   (`storage`: אסימון הקובץ מ-`fs` + שם), כדי שתיטען שוב בפתיחה הבאה.
3. שכבות GeoJSON/KML/GPX — דרך אותה שכבת ציור של קווי העירוב.
4. עינים למקרא (Leaflet): אותו מתאם כ-`L.GridLayer`.
5. כיוון תפילה: המנוע שלו עדיין נפרד (Prayer-pointA#23) — קודם להעביר אותו למפה המשותפת.
6. MapsOffline: לבקש מהמפתח פרטי פורמט / רשות; Windows Maps — לא נתמך.

## מה צריך ממך (המפתחת)
- דוגמה קטנה של קובץ `.mapsdata` (או קישור לתוכנה), ואם אפשר — פנייה למפתח MapsOffline לפרטי הפורמט.
- החלטה: האם לכלול את sql.js בכל התוספים או רק בטעינה עצלה (מומלץ: עצלה).
